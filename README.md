# Conferencia de Barrio La Concordia — Minuta Web Interactiva

Minuta interactiva y litúrgica para la Conferencia de Barrio La Concordia, diseñada con los colores azul de La Iglesia de Jesucristo de los Santos de los Últimos Días, animación reverente de entrada, orden de la reunión sacramental y enlaces directos a la Biblioteca del Evangelio oficial (`churchofjesuschrist.org`).

## 📖 Características
- **Lema**: *«Deleitaos en las palabras de Cristo; porque he aquí, las palabras de Cristo os dirán todas las cosas que debéis hacer.»* (2 Nefi 32:3).
- **Autoridades**:
  - **Dirige**: Obispo David Perez
  - **Preside**: Presidente Mendoza (Presidente de Estaca)
  - **Discursante**: Pte. Castillo Argenis
- **Himnos Oficiales en Español**:
  - Himno de Apertura: *Amazing Grace (Sublime gracia)* - Himno #1010
  - Himno Sacramental: *La Santa Cena* - Himno #103
  - Himno Especial: *Getsemaní* (Melanie Hoffman / Liahona)
  - Especial de Coro: *Como os he amado / Love One Another* - Himno #203 / #308
  - Himno Final: *Te damos, Señor, nuestras gracias* - Himno #10
- **Código QR Dinámico**: Generado al instante para que la congregación lo escanee en la capilla.
- **Modo Capilla**: Tema oscuro atenuado para lectura cómoda sin deslumbrar.

## 🚀 Despliegue en GitHub Pages
1. Crea un repositorio en tu cuenta de GitHub (por ejemplo, `minuta-la-concordia`).
2. Sube el código:
   ```bash
   git remote add origin https://github.com/TU_USUARIO/minuta-la-concordia.git
   git branch -M main
   git push -u origin main
   ```
3. En GitHub, ve a **Settings** > **Pages**.
4. En **Branch**, selecciona `main` y la carpeta `/(root)`, luego haz clic en **Save**.
5. ¡Listo! En segundos tu minuta estará publicada en: `https://TU_USUARIO.github.io/minuta-la-concordia/`
